# Smart Logistics Test (УЛ Лайт)

SPA для работы с грузовыми аукционами (тестовое задание).

## Требования

- Node.js 20+
- [pnpm](https://pnpm.io/) 10+

## Установка

```bash
pnpm install
```

## Скрипты

```bash
pnpm dev      # локальный dev-сервер
pnpm build    # production-сборка
pnpm verify   # typecheck + lint + test
```

## Проверка

После установки достаточно `pnpm verify`. На текущем этапе в приложении только пустой shell со smoke-компонентами shadcn (button/input), без страниц аукционов и MSW-handlers.
